# 台股選股 → Notion 投資帳本

GitHub 幫你定時跑程式，結果寫進 Notion 的「持股總覽」。電腦不用開著。

| 排程 | 時間（台灣） | 做什麼 |
|---|---|---|
| 每日更新現價 | 平日 17:17 | Active／Watch 的股票填入今天收盤價 |
| 每月選股 | 每月 12 日 10:23 | 全市場跑嚴格關卡，通過者新增為 Watch，帳本裡的個股更新指標 |
| 檢查資料 | 手動 | 第一次設定時確認資料抓得到 |

宏觀週報不在這裡，是 Claude 的排程每週一寫進 Notion 的。

## 第一次設定（約 10 分鐘）

1. **建立 repo**：在 GitHub 建一個新 repo（建議設成 Private），把這個資料夾的所有檔案上傳，`.github` 資料夾也要。
2. **存入兩個金鑰**：repo 的 **Settings → Secrets and variables → Actions → New repository secret**
   - `NOTION_TOKEN`：Notion 整合的 Internal Integration Secret
   - `FINMIND_TOKEN`：FinMind 會員頁的 API token
3. **檢查資料**：**Actions → 檢查資料 → Run workflow**。跑完點進去看輸出，每個科目都是 ✓ 就沒問題；有 ✗ 的話，把輸出貼給 Claude 修。
4. **小規模試跑**：**Actions → 每月選股 → Run workflow**，`limit` 填 `20`，勾選 `dry_run`。確認流程跑得通。
5. **正式跑一次**：再按一次 Run workflow，兩個欄位都留空。全市場大約要 2–4 小時（FinMind 免費額度有限速）。

之後全部自動執行，不用再管。

## 嚴格關卡（在 `config.py` 調整）

- 市值 ≥ 100 億，近 60 日平均成交值 ≥ 2,000 萬
- 近 5 年**每年** ROE ≥ 10%，平均 ≥ 15%，沒有虧損年
- 自由現金流為正 ≥ 4 年，營業現金流 ÷ 淨利 ≥ 0.8
- 負債比 < 50%，毛利率年度波動 ≤ 5 個百分點
- 本益比 < 30，且不高於同產業的 75 百分位
- 排除金融保險業與 ETF

通過的公司在彼此之間排名，算出 0–100 的「選股評分」：品質 40（平均 ROE、毛利率穩定度）、價值 30（同業本益比位置）、動能 30（近 3 個月營收年增率）。每次最多新增 30 檔。

## 寫回 Notion 的規則

- **帳本裡已有的個股**：只更新指標和「定量關卡」，**不會改你的狀態**。持有的股票沒過關，你會看到 ❌ 和未通過原因。
- **新通過的公司**：依評分高低新增，狀態 Watch、投資定位「觀察」。
- **沒過關、也不在帳本裡的公司**：不寫進 Notion，只記在 CSV 裡。
- ETF 不受影響，只會每天更新現價。

每次選股的完整結果存在 `results/screen_日期.csv`，包含每檔的未通過原因。累積一兩年後，可以拿來跟 0050 比較，驗證這套方法有沒有用。

## 已知限制

- 全市場的初篩用的是證交所和櫃買中心的單日資料（本益比、成交值），比較粗略；真正的關卡在第二階段用財報判斷。
- 市值用「收盤價 × 股本 ÷ 10」估算，假設面額 10 元。少數非 10 元面額的公司會算錯。
- 證交所和櫃買中心偶爾會改 API 欄位名稱。如果每日更新開始失敗，請 Claude 檢查 `market_data.py`。

本工具只篩選和整理資料，不構成投資建議。
